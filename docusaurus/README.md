# QA Eureka Group - docs

Situs dokumentasi (Docusaurus 3) buat Playwright + Lighthouse CI di repo `dashboard-qa`.
Isinya cuma Markdown di `docs/`. Nggak baca `latest.json`, nggak jalanin tes.

```bash
npm install
npm run start     # dev server http://localhost:3000
npm run build     # hasil statis ke build/
npm run serve     # serve hasil build
```

Halaman: `docs/intro.md`, `docs/playwright.md`, `docs/lighthouse.md`, `docs/hasil.md`.
Sidebar autogenerated dari urutan `sidebar_position` di frontmatter.

Deploy statis (build/ bisa ditaruh di subdomain kantor apa aja).
