# Per-run reports

Run `node scripts/build-run-docs.mjs <runDir>` from any directory with Node 20+ and dependencies installed in `docusaurus`. Required inputs: `run.json`, `logs.txt`. Place Playwright JSON, optional step reporter JSON, Lighthouse JSON, native HTML report directories, screenshots and trace ZIPs under `<runDir>/artifacts/`. Playwright JSON is recognized by `suites`; Lighthouse by `audits` and `categories`.

Output: `<runDir>/docs/`, built by actual Docusaurus CLI. Build output, including stderr, streams to stdout. Nonzero build exits propagate. Each invocation uses an isolated temporary site; old Docusaurus docs and custom reporting scripts remain untouched. Rebuilding replaces only prior generated docs output.

Set `REPORT_BASE_URL=/reports/<runId>/docs/` to match serving mount. Default uses that path for UUID run IDs, otherwise `/`. Serve complete docs over HTTP; file:// is unsupported. Authenticate both report page and static assets. Native HTML artifacts execute their own scripts; only publish trusted runner artifacts and consider isolated origin for untrusted suites.

Only `artifacts/**` and `logs.txt` are copied to `docs/artifacts/` with run-relative paths retained. Symlinks are skipped. `run.json` is not published; displayed metadata has an explicit allowlist excluding case source snapshots. Runner must keep credentials/source files out of artifact directory and redact secrets in logs and artifacts. Playwright reports and traces can themselves contain tested page source and private data.

Report data renders as React text and preformatted JSON, never MDX or raw HTML. Generated report index is static read-only HTML: built CSS is inlined and client scripts removed, preserving opaque-origin sandbox isolation without authenticated CSS/JS subrequests. Native details disclosures and download links work without hydration; interactive native reports remain offline downloads. Existing reports need rebuilding to receive this fix. Metadata/log snapshots precede documentation completion; live runner remains final status authority. Native report folders retain data assets. Native HTML links download for offline use because sandboxed inline viewers cannot reliably fetch data. Builder creates `docs/downloads/artifacts.tar.gz` from staged regular artifact files and logs using native `tar` (available in current Windows and Linux images). It excludes symlinks and source snapshots. If tar is unavailable, report shows an explicit warning and individual downloads remain available. Trace download instructions use local `npx playwright show-trace`, not online uploads.

Check: `node scripts/test-run-docs.mjs` creates synthetic failed run, executes real Docusaurus production build, verifies escaped hostile text, failure details, mounted asset paths, preserved native assets, trace bytes and exclusion of case source snapshots, then removes fixture.
